# Faro demo build plan

Saved at the user’s request on 1 November 2026. Removed from both proposal PDFs; retain for building demos.

Demonstrate the same modular architecture as the proposal:

- Incomplete and complete questions: follow up only when needed.
- A supported comparison with sources, dates, and checked facts.
- Missing information, forbidden access, and service failure: explain limits without unsupported answers.
- Repeated requests within a company: demonstrate both data caching and AI-result caching, with permissions and freshness checks. Include a colleague asking while Maria is on holiday.
- A second compatible client connection: reuse services through the shared data format, preserving company separation.
- A client task reviewed for correctness, task completion, time, and cost.

Expand supported tasks and connections from observed results. Keep service boundaries and add checks appropriate to each task.

Implementation foundations: Luna, Nemo, Japan follow-up/cache patterns, AI2Analytics. Decision API classification experiment supports faster decisions and fewer output tokens, not identical classifications or lower total tokens.
